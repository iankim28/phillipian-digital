# Put these on the website

These are the only two files in this repo that go on phillipian.net. A webmaster copies them once. The steps are in [how to put this on the site](../guides/how-to-put-this-on-the-site.html).

- `halfway.js` counts when a reader scrolls to the middle of a story.
- `slot-clicks.js` counts which spot on the front page the click came from: the lead, top stories, news, sports, commentary, or arts.

They do not record a reader’s name. They do not write the Monday note. The program that writes the five lines is in [make-the-monday-note](../make-the-monday-note/).
